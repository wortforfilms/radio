Rule Keep Compatibility

Do not move existing public HTML files until a shim or redirect preserves the current file URL.

Rule Separate Data From Views

Future station, track, lyric, storyboard, and evidence records should live in `data/` before UI pages consume them.

Rule Fail Closed

Missing source, creator, receipt, citation, timing, or verification remains NULL in every lane.

Migration

Phased Move Plan

Phase 01: keep current files, add structure manifest
Phase 02: extract shared data into data/*.json
Phase 03: split repeated UI into surface modules
Phase 04: move Three.js runtime assets into runtimes/threejs
Phase 05: add import/export lanes and schema validation
Phase 06: create compatibility shims for any moved public HTML
Phase 07: add browser QA snapshots and evidence reports
Phase 08: promote only verified surfaces, keep draft surfaces labeled
